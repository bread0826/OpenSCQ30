# Studio White Android assets

- The Liberty 4 NC illustration is a transparent ImageGen extraction from the approved user-supplied mockup. It retains the product markings from that reference.
- The adaptive launcher artwork was recreated from the same mockup using Android vector and shape resources.
- Doto is bundled from the [Google Fonts distribution](https://github.com/google/fonts/tree/main/ofl/doto) under the [SIL Open Font License](android-doto-OFL.txt).
